## ✨ Features

* 🧾 Manage personal health records
* 💊 Track medications and prescriptions
* 📊 Monitor vital data (BP, Sugar, Weight, etc.)
* 🔔 Set reminders and alerts
* 🔐 Secure login with **4-digit PIN**
* 📈 View health history and trends
* 👤 Profile management
